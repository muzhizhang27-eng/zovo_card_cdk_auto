## 安全修复与检查

1. 新增服务端会话，退出、改密码、禁用或删除管理员后撤销登录；限制 HS256、issuer、过期时间和会话标识。
2. 生产使用 Secure、HttpOnly、host-only 认证 Cookie，以及绑定会话的 CSRF 校验和同源写入校验；明文认证请求拒绝。
3. 登录限速在校验前原子计数，限制总量和存储规模；反代覆盖客户端伪造的来源 IP。
4. 上游地址按服务器允许列表限制；卡台探测和 API 禁止重定向携带 Key；带幂等键的购买请求也禁止 HTTP 库在断连后隐式重发。
5. 修复把同步回来的历史库存误报为本次发码成功的问题；前端保存待核对请求与幂等键，跨标签互斥，刷新或不确定响应不会重新购买。
6. 移除浏览器持久保存的登录令牌及完整 CDK；限制 API 同源、跳转和外链；修复严格 CSP 下的翻译运行兼容性。
7. 新管理实例在应用和 Nginx 两层隔离公开兑换、初始化、webhook 和代理换码；关闭网页自更新，避免未发布的安全修复被旧 release 覆盖。
